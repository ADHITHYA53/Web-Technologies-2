
# Web Technology Assignment 2

## Overview
This repository contains three Web Technology assignment projects developed at KPR Institute of Engineering and Technology.

## Projects

### 1. Student Registration Form
- Developed using HTML, CSS, and JavaScript.
- Includes student details, email, course, password, and file upload fields.
- Provides client-side form validation and responsive design.

### 2. Student Admin Portal
- Developed using PHP, MySQL, HTML, and CSS.
- Supports adding, viewing, editing, and deleting student records.
- Supports document uploads, downloads, and search functionality.
- Stores student information and file metadata in MySQL.

### 3. Student Portal Using Servlets and JDBC
- Developed using Java Servlets, JSP, JDBC, and MySQL.
- Retrieves and displays student records dynamically.
- Supports student profile viewing and document streaming.
- Includes login, session management, and separate Admin and Student dashboards.

## Technologies Used
- HTML5, CSS3, JavaScript
- PHP
- Java 21
- Java Servlets and JSP
- JDBC
- MySQL
- XAMPP
- Apache Tomcat 10.1
- Apache Maven

## Setup Instructions
1. Install XAMPP, JDK 21, Apache Tomcat 10.1, and Maven.
2. Import the database schema into MySQL.
3. Place the PHP project inside the XAMPP `htdocs` directory.
4. Configure the database connection settings.
5. Build the Java project using `mvn clean package`.
6. Deploy the generated WAR file to Tomcat's `webapps` directory.
7. Start the required services and open the applications in a browser.

## Learning Outcomes
- Developing responsive web interfaces.
- Validating forms using JavaScript.
- Performing CRUD operations using PHP and MySQL.
- Connecting Java applications to MySQL using JDBC.
- Creating dynamic web pages using Servlets and JSP.
- Handling file uploads, downloads, and user sessions.

## Conclusion
These projects demonstrate practical applications of web technologies in student registration, student record management, and Java web development. They provide experience in frontend development, database connectivity, file handling, and session management.
